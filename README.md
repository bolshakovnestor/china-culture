# 华夏 · Довідник китайської культури

Інтерактивний навчальний довідник з китайської культури для студентів-китаїстів. Статичний сайт (HTML + CSS + JS), без серверу, без збірки і без ШІ — працює на GitHub Pages безкоштовно.

## Що всередині

- **14 тем**: держава, мова та ієрогліфи, історія і династії, філософія, свята, кухня, чай, мистецтво, література, чотири великі винаходи, зодіак і символи, пам'ятки ЮНЕСКО, етикет, ушу та традиційна медицина.
- **Інтерактивна мапа** 34 одиниць провінційного рівня: режими «регіони / населення / тип», картка з центром, скороченням, населенням (перепис 2020), пам'ятками, кухнею; гра «Знайди провінцію».
- **Кожне китайське слово** подано ієрогліфами, піньїнем і перекладом; клік — озвучення (Web Speech API браузера).
- **Віджети**: тони і піктограми, стрічка династій, калькулятор зодіаку, вірш Лі Бо у вертикальному записі, шість категорій чаю, вісім кухонь на мапі.
- **Словник** з пошуком (ієрогліфи / піньїнь без тонів / українською), картки, позначки «вивчено».
- **Тести** по кожній темі, мікс і автогенерований тест з провінцій. Прогрес зберігається в браузері.
- **Джерела** наведено внизу кожної теми.

## Як опублікувати на GitHub Pages

1. Створи публічний репозиторій (наприклад, `china-culture`).
2. Завантаж у корінь репозиторію весь вміст цієї папки (`index.html`, `css/`, `js/`, `.nojekyll`, `README.md`).
   - Через сайт: **Add file → Upload files**, перетягни файли й папки, **Commit changes**.
   - Або з терміналу:
     ```bash
     git init && git add . && git commit -m "Initial site"
     git branch -M main
     git remote add origin https://github.com/<логін>/china-culture.git
     git push -u origin main
     ```
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/ (root)` → **Save**.
4. За 1–2 хвилини сайт буде доступний за адресою `https://<логін>.github.io/china-culture/`.

## Структура

```
index.html            — каркас сторінки
css/style.css         — стилі
js/app.js             — маршрутизація, мапа, словник, тести, віджети
js/data-topics-1.js   — теми (держава … чай)
js/data-topics-2.js   — теми (мистецтво … ушу), вірш, зодіак, чаї, кухні
js/data-provinces.js  — дані провінцій
js/data-images.js     — відповідність «ієрогліфи → стаття Вікіпедії» для фото
js/map-paths.js       — контури мапи (згенеровано з Apache ECharts 4 china.json, Apache-2.0)
```

## Як додати або виправити матеріал

У текстах використовується синтаксис `{汉字|pīnyīn|переклад}` — він автоматично перетворюється на інтерактивний термін з озвученням. Нова тема — це ще один об'єкт у масиві `TOPICS` (поля `sections`, `vocab`, `quiz`, `sources`).

## Примітки

- Фото (банери тем, пам'ятки й страви провінцій, картки тем, галерея на головній) завантажуються з Wikipedia/Wikimedia Commons через публічний API; натискання відкриває фото на весь екран із посиланням на джерело. Якщо фото немає — показується стилізована заглушка з ієрогліфами.
- Для озвучення потрібен китайський голос у системі (є за замовчуванням у Chrome, Edge, Safari, Android, iOS).
- Тайвань показано на мапі з приміткою про спірний статус; дані про Гонконг і Макао — з їхніх переписів 2021 р.
